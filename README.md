# ARK — финансовый навигатор

Статическое, адаптивное веб-приложение для планирования финансовой независимости: смены Ozon, жизнь в Санкт-Петербурге, подушка, кредитка, покупки и каталог KIT из Anytype.

## Быстрый запуск

Откройте `index.html` в браузере. Ничего устанавливать не нужно: всё работает локально, без сервера и зависимостей.

## GitHub Pages

1. Создайте публичный или приватный репозиторий (условия Pages зависят от тарифа).
2. Загрузите `index.html` и `README.md` в корень ветки `main`.
3. В GitHub откройте **Settings → Pages → Build and deployment**.
4. Выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, сохраните.
5. Используйте адрес, который появится в GitHub Pages.

## Что можно менять

- Ставка за смену в Саратове (4 000 рублей) и консервативная (3 000 рублей), ставка в Петербурге (4 800 рублей).
- График (через день / 3 смены еженедельно), дата старта и число первых зарезервированных смен.
- Модель квартиры: аренда **30 000 рублей**, коммуналка, залог и комиссия, вместо привязки к конкретным объявлениям.
- Постоянные платежи: питание, связь, метро, такси, кредитная карта, прочие расходы.
- Поездка, мебель, одежда, постельное бельё, химия и двухмесячная подушка.
- Список покупок и бюджет по ним.

## Данные

Изменения сохраняются **в localStorage** того браузера, где открыт сайт. Для переноса между устройствами используйте кнопки **Экспорт JSON** и **Импорт JSON**. Никакие финансовые данные не передаются на сервер.

## KIT

Архив Anytype от 15.11.2026 содержит только коллекции Markdown и ссылки на позиции; полноценные карточки, фото и оригинальные медиафайлы в архиве отсутствуют. В разделе KIT воспроизведены восемь коллекций и их читаемые названия. Неразрешимые внутренние ID пропущены. Если позже будет полный экспорт объектов и медиа, каталог можно расширить.

## Важные допущения

Калькулятор — **план**, а не подтверждённые выплаты. Только ночная смена 16 ноября 2026 года в исходном расписании подтверждена. Первые 15 смен включают эту смену; 4 000 рублей планируется направить на остаток ноябрьского платежа по кредитке. 40 000 рублей — отдельный резерв на поездку в Петербург. Стоимость аренды, комиссий, покупок и остальные числа — оценки пользователя; внешние цены не проверяются. Итоговые расчёты смен не учитывают все промежуточные денежные потоки и сроки фактической выплаты. Планирование задолженности без ставки процентов — только грубая нижняя оценка времени погашения.
